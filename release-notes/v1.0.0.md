MediaForge 1.0 is a Windows app for converting, joining and downloading video and audio, built on ffmpeg and yt-dlp.

## Install

Download **MediaForge_setup_v1.0.0.exe** below and run it. It installs MediaForge for your account (no administrator rights needed), adds it to the Start menu and, if you like, the desktop. ffmpeg is included.

Windows may show "Windows protected your PC" because the installer isn't code-signed yet. Choose **More info > Run anyway**.

## What's in 1.0

- **Convert**: re-encode, trim, resize, change frame rate or pull out the audio, in batches, with presets.
- **Join**: put clips in order and merge them into one video; sizes, frame rates and audio are matched for you.
- **Download**: save video or audio from links with yt-dlp, pick a format or let it choose the best quality.
- **Queue**: pause, resume and retry jobs; unfinished jobs come back after a restart.
- **Updates**: MediaForge checks GitHub for new versions and asks before installing them. ffmpeg and yt-dlp update from inside the app too. Every download is checksum-verified.
- **A new look**: dark colourways, the new anvil logo, and smooth, interruptible motion.

## Checksums

Each installer comes with a `.sha256` file. MediaForge uses it to verify updates before installing them.
