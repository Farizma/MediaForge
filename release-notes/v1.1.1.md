A fix for updating MediaForge.

## Fixes

- **Updates no longer fail with "Access is denied".** The setup wizard now asks for administrator permission and installs MediaForge for all users. Before, it installed per user without asking, so an update to a copy in a protected folder such as Program Files couldn't replace its files.
- **One entry in Settings > Apps.** A copy installed the old per-user way is upgraded in the same folder, and its old per-user entry and Start-menu shortcut are removed.
- **Drag and drop keeps working after an update.** MediaForge started from the setup wizard's last page runs as you, not as administrator, so Windows still lets you drag files from Explorer into it.

## Updating

Choose **Updates** in the sidebar, then **Update** next to MediaForge. Click **Yes** when Windows asks for administrator permission. If you're on 1.1.0 and an update stopped with "Access is denied", right-click **MediaForge_setup_v1.1.1.exe** below and choose **Run as administrator**.
